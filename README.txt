Nuit Works - website
====================

QUICKEST LOOK
-------------
Open  dist/index.html  in any browser (double-click it).
The CSS and JavaScript are inlined, so the page itself is one file.

Keep the  assets/  folder next to it. The only thing loaded from there is
the music track (5.4 MB), which is far too big to inline sensibly - so it
stays a separate file and is only downloaded if a visitor presses play.
Without assets/ the page works exactly as before, minus the player, which
removes itself if the track cannot be found.

Needs an internet connection the first time: the animation libraries
(GSAP, Lenis) and the Google Fonts are loaded from a CDN.

Best viewed on a desktop browser. The particle background uses WebGL and
there is a custom cursor with a motion trail on mouse-and-keyboard devices;
phones get a simplified version automatically.


THE SOURCE FILES
----------------
index.html      landing page markup
calculate.html  website cost calculator page
styles.css      all styling, both pages
app.js          WebGL particle field, smooth scroll, cursor, scroll animations
calc.js         calculator logic (calculate.html only)
assets/         logo, favicon, project shots and the music track
build.sh        regenerates the dist/ files from the source files above

There is no build step or install needed to work on it - edit the source
files and open index.html directly.


dist/
-----
index.html      standalone single-file landing page (deploy this anywhere)
calculate.html  standalone single-file calculator page
artifact.html   body-only fragment of the landing page, for embedding

Both are generated by build.sh. Do not edit them by hand; edit the
source files and re-run  bash build.sh  instead.
